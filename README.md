# UniMentor
A Flutter-based mobile application that focus on connecting mentors and mentees among students through matching, booking and learning resources.

UniMentor is a mobile application developed as a Final Year Project to facilitate mentor-mentee connections and provide a centralized platform for mentoring activities.

## Overview

UniMentor allow students to discover and connect with suitable mentors based on their preferences.
It provides features for communication, mentor matching, bookings, learning materials, reviews and mentoring-related activities.

## Features

- 👤 Mentor and mentee registration
- 🔍 Mentor-mentee matching
- 💬 Chat functionality
- 📅 Mentor booking
- 💳 Online and physical booking options
- 📚 Learning materials
- ⭐ Ratings and reviews
- 🏆 Co-curriculum certificate management

## Technologies

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Android Studio
